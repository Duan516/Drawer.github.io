## 项目卡片大小统一（分析完成，只读）
- 用户需求：5 张项目卡片大小一致、封面图比例一致
- 现状：`_includes/projects.liquid` 中图片有 `style="height: 60%"` inline style，但父元素 `.card` 高度是内容撑开的（auto），百分比高度无效 → 图片按原始比例显示
- 5 个封面图比例实测：红山-温室内部 1.47、纸间0 1.84、猜城记-封面 1385×2612 竖版 0.53（最突兀）、另两个待查（浮榕-封面/法国-封面）
- 方案：`projects.liquid` 把 `height: 60%` 改为 `aspect-ratio: 3/2; object-fit: cover; width: 100%; height: auto;`，删掉 card-body 的 `height: 40%`；`_sass/_base.scss` `.card-body` 加 flex 纵向 space-between
- 猜测：猜城记封面竖版裁 3:2 只留中间段，需提醒用户
- **重要发现**：`_includes/figure.liquid` 不渲染 `include.style` 参数（只处理 min/max-width/height）→ projects.liquid 里的 style 参数一直无效，之前 height:60% 和这次 aspect-ratio 都没生效
- `card-img-top` 同时被 projects.liquid 和 sketches.liquid（主页速写瀑布流）使用 → 不能全局改，必须限定 `.projects .card img`
- 最终方案：`_sass/_base.scss` 第 693-697 行 `.projects .card img` 块内加 `aspect-ratio: 3 / 2; object-fit: cover;`（img 有 width 100% + height auto 属性，aspect-ratio 可生效）；建议删掉 projects.liquid 里无效的 style 参数
